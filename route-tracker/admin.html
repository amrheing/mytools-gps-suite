Auto-Route Settings

Automatically create a new route every day at the specified time. Previous active route will be completed.

Default: 00:00 (midnight)
How it works
  • Server checks every minute if it's time to create a new route
  • Any active route is automatically completed before creating the new one
  • New route gets name format: "Auto Route MM/DD/YYYY"
  • GPS tracking continues seamlessly with the new route
