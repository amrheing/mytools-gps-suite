OwnTracks Setup

Configure OwnTracks (HTTP mode):

  1. Set Mode: HTTP
  2. Set URL: https://tracker.route-tracker.de
  3. Set UserID: your username
  4. Set Password: your app password
  5. Set DeviceID: any name (e.g. iphone) — auto-registers on first push

The DeviceID you set becomes the device name visible on the map.
