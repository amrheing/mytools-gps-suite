Quick Start

Get tracking in under 5 minutes.

1 · Open the app

Navigate to https://route-tracker.de and log in with your credentials.

2 · Install OwnTracks

  1. Download OwnTracks from the App Store or Google Play.
  2. Open Settings → Connection and set Mode to HTTP.
  3. Set the URL to https://tracker.route-tracker.de.
  4. Enter your Route Tracker username and password.
  5. Set a Device ID (e.g. iphone or pixel) — it auto-registers on first push.
  6. Save and return to the map view — OwnTracks will start sending positions.

The Device ID becomes the device name visible on the map. Pick something meaningful like gerald-iphone.

3 · View your position

Open the app, select your device from the dropdown in the control panel, and watch the map update as positions arrive.

4 · Explore the app

Read the User Guide for a full feature reference, or the Admin Guide if you manage users and devices.

Schnellstart

In unter 5 Minuten loslegen.

1 · App öffnen

Navigiere zu https://route-tracker.de und melde dich mit deinen Zugangsdaten an.

2 · OwnTracks installieren

  1. Lade OwnTracks aus dem App Store oder Google Play.
  2. Öffne Einstellungen → Verbindung und setze den Modus auf HTTP.
  3. Trage als URL https://tracker.route-tracker.de ein.
  4. Gib deinen Route-Tracker-Benutzernamen und dein Passwort ein.
  5. Lege eine Geräte-ID fest (z. B. iphone oder pixel) – sie wird beim ersten Push automatisch registriert.
  6. Speichern und zur Kartenansicht zurückkehren – OwnTracks sendet nun Positionen.

Die Geräte-ID wird zum Gerätenamen auf der Karte. Wähle etwas Aussagekräftiges wie gerald-iphone.

3 · Position anzeigen

Öffne die App, wähle dein Gerät im Dropdown der Steuerungsleiste und beobachte die Kartenaktualisierungen.

4 · App erkunden

Lies das Benutzerhandbuch für eine vollständige Funktionsreferenz oder das Admin-Handbuch für Benutzer- und Geräteverwaltung.

Logging In

Open https://route-tracker.de. If no session is active you are redirected to the login page. Enter username and password, then click Login.

Auto-Route

Automatically completes the current route and starts a new one at a scheduled time each day.

  1. Click 🤖 next to any device.
  2. Enable auto-route creation and set the daily creation time.
  3. Click Test Now to create a route immediately.
  4. Click Save Settings.

Auto-route only triggers if the device received GPS data in the last 24 hours — inactive devices are skipped.

Alternative GPS Endpoint

Both URLs point to the same /api/gps handler:

  • https://tracker.route-tracker.de
  • https://gps.route-tracker.de

How it works

  1. OwnTracks sends a POST request with JSON body each time your position changes or at the configured interval.
  2. The server authenticates via HTTP Basic Auth (username + password).
  3. The device ID is extracted from the OwnTracks topic (owntracks/<user>/<device>). Fallback: tid, then default-device.
  4. If no active route exists (or the last point is older than 2 hours), a new route is created automatically.
  5. The point is appended to the route and the map updates on the next poll.

Message Types

TypeHandled
locationStored as GPS point
transitionAcknowledged (200 empty array), not stored
waypoint, othersAcknowledged (200 empty array), not stored

Battery Tips

  • Use 10–30 s intervals for everyday tracking — good balance of accuracy and battery.
  • Use 5 s intervals only when actively navigating.
  • On iOS: enable Significant Location Changes as a background fallback.

  • https://gps.route-tracker.de

Funktionsweise

  1. OwnTracks sendet bei Positionsänderungen oder im festgelegten Intervall eine POST-Anfrage mit JSON-Body.

  3. Die Geräte-ID wird aus dem OwnTracks-Topic (owntracks/<user>/<device>) extrahiert. Fallback: tid, dann default-device.

Export Formats

Routes can be downloaded in four formats from the Export panel in the left column.

GPX — GPS Exchange Format

Best for: GPS devices, Strava, Garmin Connect, Komoot, OsmAnd

  • Industry standard for GPS track exchange.
  • Contains track points with timestamps, latitude, longitude, elevation, speed.
  • Compatible with virtually all navigation and fitness apps.

KML — Keyhole Markup Language

Best for: Google Earth, Google My Maps

  • Includes visual styling (coloured line, start/end markers).
  • Contains route description and metadata.
  • Can be opened in Google Earth for 3D visualisation.

JSON

Best for: Backup, custom analysis, re-import

  • Complete route object with all metadata, timestamps, and statistics.
  • Useful for scripting and integration with other tools.

CSV

Best for: Spreadsheet analysis (Excel, LibreOffice Calc, Python)

  • One row per GPS point.
  • Columns: timestamp, latitude, longitude, altitude, speed, accuracy, heading.

Calendar Export

Export all routes in a date range as a single GPX file.

  1. Open the calendar section in the left column.
  2. Click a date or drag to select a range.
  3. Click Export Range as GPX.

Exportformate

Routen können in vier Formaten aus dem Export-Panel in der linken Spalte heruntergeladen werden.

GPX — GPS Exchange Format

Geeignet für: GPS-Geräte, Strava, Garmin Connect, Komoot, OsmAnd

  • Industriestandard für den GPS-Track-Austausch.
  • Enthält Trackpunkte mit Zeitstempeln, Breitengrad, Längengrad, Höhe und Geschwindigkeit.
  • Kompatibel mit nahezu allen Navigations- und Fitness-Apps.

KML — Keyhole Markup Language

Geeignet für: Google Earth, Google My Maps

  • Enthält visuelle Gestaltung (farbige Linie, Start-/Endmarker).
  • Beinhaltet Routenbeschreibung und Metadaten.
  • Kann direkt in Google Earth für 3D-Visualisierung geöffnet werden.

JSON

Geeignet für: Sicherungen, eigene Analysen, Wiederimport

  • Vollständiges Routenobjekt mit allen Metadaten, Zeitstempeln und Statistiken.
  • Nützlich für Skripte und die Integration mit anderen Werkzeugen.

CSV

Geeignet für: Tabellenkalkulationen (Excel, LibreOffice Calc, Python)

  • Eine Zeile pro GPS-Punkt.
  • Spalten: Zeitstempel, Breitengrad, Längengrad, Höhe, Geschwindigkeit, Genauigkeit, Richtung.

Kalender-Export

Alle Routen eines Datumsbereichs als einzelne GPX-Datei exportieren.

  1. Kalenderbereich in der linken Spalte öffnen.
  2. Datum anklicken oder Bereich auswählen.
  3. Klicke auf Bereich als GPX exportieren.
