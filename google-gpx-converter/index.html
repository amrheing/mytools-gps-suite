     Supported URL Formats
    
                    
    We support various Google Maps URL formats
    
                    
    The GPX file contains each stop as a waypoint and all stops as a route, so your navigation device calculates the way itself.
    
                
    
                
      
                    
    •  Short URLs: https://maps.app.goo.gl/xyz123
      • 
                    
    •  Places: https://www.google.com/maps/place/Name/@50.38,8.05,13z/…
      • 
                    
    •  Coordinates: https://www.google.com/maps/@40.7128,-74.0060,15z or 50.3836, 8.0503
      • 
                    
    •  Place queries: https://maps.google.com/maps?q=50.3836,8.0503
      • 
                    
    •  Directions: https://www.google.com/maps/dir/Start/End
      • 
                
    
                
                
    
                    
     Short URL Help
    
                    
    Short links like maps.app.goo.gl/xyz123 are expanded automatically when you convert. Only the link ID is sent to Google, from this server.
    
                    
                    
    If that fails:
    
                    
    
                        
    
                            
    1
    
                            
    Open the short URL in your browser
    
                        
    
                        
    
                            
    2
    
                            
    Copy the full URL from your browser's address bar
    
                        
    
                        
    
                            
    3
    
                            
    Paste that expanded URL here instead
    
                        
    
                    
    

                    
     Getting Coordinate URLs
    
                    
    Some shared places contain only a name and no coordinates. Then:
    
                    
    
                        
    
                            
    1
    
                            
    Find the location on Google Maps
    
                        
    
                        
    
                            
    2
    
                            
    Right-click on the exact spot
    
                        
    
                        
    
                            
    3
    
                            
    Click the coordinates at the top of the menu to copy them
    
                        
    
                        
    
                            
    4
    
                            
    Paste them here as a line of their own, e.g. 50.3836, 8.0503

     About GPX
    
                
    GPX (GPS Exchange Format) is a data format for exchanging GPS data between applications and devices.
