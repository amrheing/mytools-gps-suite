# Google Maps to GPX Converter - Copilot Instructions

## What it is
A static page that converts Google Maps links (short links, places, routes, query links, plain coordinates)
into a GPX 1.1 file. Served by nginx (Docker, port 6010); on www.amrhein.info embedded via iframe.

## Files
- `index.html` - UI (styles come from the mounted `shared/shared-styles.css`)
- `parser.js` - pure functions: `parseMapUrl`, `shortLinkInfo`, `generateGPX`, `fileNameFor` (no DOM; used by the tests)
- `script.js` - UI class `GoogleMapsToGPXConverter`
- `url-expander.js` - calls the own short link resolver `expand/<app|goo>/<id>`
- `nginx.conf`, `expand.inc` - static files, security headers (CSP), short link resolver with rate limit
- `tests/parser.test.js` - `node --test google-gpx-converter/tests/`

## Rules
- No third-party services from the browser (no CORS proxies, no URL expander APIs). Only Font Awesome from cdnjs (with SRI).
- Keep the CSP working: no inline scripts, no `eval`.
- GPX element order must follow the schema: metadata, wpt, rte, trk.
- Parsing must never throw for a recognised Google Maps link; return unresolved names instead.
- UI texts are English; the German translation lives in the website repo (`public/tool-theme/i18n-de.js`).
  When you add or change a visible text or a status message, add the German entry there.
- Add a test for every new URL format.
